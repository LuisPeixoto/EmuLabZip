# Flutter demo app

A small Flutter app used to try EmuLabZip's Flutter tools: a list, a button that makes every frame slow
(**Jank: on** blocks the UI thread for 50 ms per build) and a button that allocates 2 MB each time.

You need the Flutter SDK. The scripts look for it in `$FLUTTER_HOME`, then on the `PATH`.

```bash
tools/flutter-app/install.sh android        # builds a debug APK and installs it on the running emulator
tools/flutter-app/install.sh ios            # builds for the booted iOS Simulator and installs it
```

Then, with the app open:

```bash
emulabzip frameworks dev.emulabzip.flutterdemo
emulabzip flutter tree dev.emulabzip.flutterdemo
emulabzip flutter frames dev.emulabzip.flutterdemo --seconds 10   # tap "Jank: on" and scroll the list meanwhile
emulabzip flutter memory dev.emulabzip.flutterdemo                # tap "Allocate" a few times first
```

Only debug and profile builds have a Dart VM service. The platform folders (`android/`, `ios/`) are generated by
`flutter create` on the first run and are not kept in the repository.
