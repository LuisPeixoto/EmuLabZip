# React Native demo app

A small React Native screen (a title, a counter, a switch and a list, in nested components with props) used to try
EmuLabZip's React Native tools. The project itself is generated by the React Native CLI into `build/` (not kept in
the repository); only the screen, `App.tsx`, lives here.

You need Node 22+, a JDK 17+ and the Android SDK. The first run downloads a lot and takes several minutes.

```bash
tools/rn-app/install.sh --start     # builds, installs on the running emulator, starts Metro
```

With the app open on the device:

```bash
emulabzip frameworks dev.emulabzip.rndemo
emulabzip rn tree dev.emulabzip.rndemo
emulabzip rn heap dev.emulabzip.rndemo
emulabzip rn console dev.emulabzip.rndemo --seconds 20     # tap the button meanwhile
```

Metro lets one debugger connect at a time, so close React Native DevTools and Chrome's inspector first.

## A release build

```bash
tools/rn-app/install.sh --release
```

This builds the app with Hermes and the JavaScript bundled in it. Tap **Crash**: the JS error is thrown a few calls
deep in `App.tsx`. The source maps Metro and Hermes write are printed at the end; add the composed one with
`emulabzip mappings add` to read the stack.
