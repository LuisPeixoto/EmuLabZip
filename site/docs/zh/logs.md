# 日志

日志查看器在同一张表中跟踪 Android 上的 **logcat** 和 iOS 上的**统一日志**，列相同：
时间、进程 id、级别、标签和消息。

## 过滤器

| 控件 | 作用 |
|---------|--------------|
| **V D I W E F** | 最低级别。点击 **W** 会显示警告、错误和致命行。 |
| **Tag** | 标签包含该文本的行（不区分大小写）。 |
| **Search** | 消息或标签包含该文本的行。按 <kbd>⌘F</kbd> 跳到这里。 |
| **.\*** | 将搜索内容视为正则表达式，例如 `skipped \d+ frames`。无效的表达式会让输入框变红。 |
| **App** | 只显示由工具栏中所选应用写入的行。 |

在 iOS 上，`Default` 消息显示为 **I**，`Fault` 消息显示为 **F**。在 Android 上，`A`（assert）显示为
**F**。

## 阅读

- 当你位于底部时，列表会跟随新的行。向上滚动即可停止跟随；**Jump to latest** 会带你
  回到最新位置。
- **Pause** 会冻结视图，但不会停止数据流。这期间到达的行会在你继续后出现。
- 点击某一行可查看完整消息、线程 id 以及（在 iOS 上）子系统。双击某一行可复制它。

## 导出

下载按钮会导出**你当前看到的行**（过滤之后），格式为 logcat 的 `threadtime`
布局的纯文本，或 JSON 行（每行一个对象）。命令行可以用 `emulabzip logs --json` 做同样的事。

## 限制

查看器默认保留最新的 50,000 行；可以在 Settings 中更改。当行到达的速度超过
界面显示的速度时，状态栏会统计被丢弃的行数，而不是隐瞒这一事实。
