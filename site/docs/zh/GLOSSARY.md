# 术语表：简体中文

称呼用“你”。语气直接、专业，与英文一致。中文与英文之间加空格（例如“使用 Android 模拟器”）。请始终使用下列术语。

| English | 中文 |
|---|---|
| emulator / simulator | 模拟器 |
| device | 设备 |
| log, logcat | 日志，logcat |
| crash, ANR | 崩溃，ANR |
| stack (trace) | 堆栈 |
| request / response | 请求 / 响应 |
| proxy | 代理 |
| mock (noun, verb) | 模拟响应（动词：模拟） |
| breakpoint | 断点 |
| rule | 规则 |
| flow (recorded steps) | 流程 |
| session | 会话 |
| baseline | 基线 |
| budget | 预算 |
| timeline | 时间线 |
| replay | 回放 |
| snapshot | 快照 |
| heap dump | 堆转储 |
| leak | 泄漏 |
| trace, flame graph | 追踪，火焰图 |
| deep link | 深层链接 |
| layout | 布局 |
| accessibility | 无障碍 |
| storage (the tool / the app's files) | Storage 工具；存储（应用的文件） |
| performance | 性能 |
| memory | 内存 |
| start time | 启动耗时 |
| build | 构建 |
| release | 版本 / 发布 |

| theme | 主题 |
