# WebSocket 消息

[Network](network.md) 工具按消息而不是按字节读取 WebSocket 流量。打开一个 WebSocket 请求，**Messages** 标签页会列出双向传输的内容，并显示自连接建立以来经过的时间。

- **箭头**表示方向：向上是从应用发往服务器，向下是从服务器返回。
- 文本消息以文本显示，打开 JSON 消息时会自动格式化。二进制消息显示为十六进制转储。
- 过滤器会在文本消息内部查找。
- 控制帧（ping、pong、close）也会列出。

## 读取方式

代理仍然原样转发应用与服务器之间的每个字节，只是旁听。它遵循 RFC 6455：支持 7 位、16 位和 64 位长度的帧、掩码、重新拼合成一条的分片消息、夹在分片之间的控制帧，以及双方协商一致时的 `permessage-deflate`（包括 `no_context_takeover`）。如果传输的内容其实不是 WebSocket，读取会悄悄停止，连接继续正常工作。

## 限制

一个流程最多保留 1,000 条消息，每条最多保留 64 KB；标签页会告诉你有多少后续消息没有保留，以及哪条消息被截断。计数会继续累加。[HAR 导出](network.md#export)会像 Chrome 一样，把这些消息放在 `_webSocketMessages` 中。
